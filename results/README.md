# Results Directory

This directory contains curated result summaries for the fixed-confidence experiment.

Use `fixed_confidence_paper_main_table_abs_rho.csv` for paper writing. It reports absolute reward-proxy correlation as the proxy-strength diagnostic because signed negative correlation can still be useful with a signed control variate.

Repetition-level replay traces are generated by `scripts/05_run_fixed_confidence_replay.py` but are excluded from git.
